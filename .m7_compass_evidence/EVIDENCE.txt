1. ROOT CAUSE (pointer interception, not visibility, not bearing re-apply)
--------------------------------------------------------------------------------
android/maps_interaction_patch/java/io/flutter/plugins/googlemaps/
NtPrecisionMapView.java — the M3.2 Pass 2 precision tap layer — cancelled EVERY
completed single-finger tap before the SDK saw ACTION_UP and consumed the event:

    if (completedTap && interaction != null && interaction.enabled()) {
      ... super.dispatchTouchEvent(cancel);   // SDK sees DOWN then CANCEL
      interaction.tap(x, y);                  // Dart decides what the tap meant
      return true;                            // real UP never reaches the SDK
    }

The Google Maps SDK's docked controls (the top-left compass among them) sit in
the same view hierarchy, so their click could never complete. Result: the needle
was drawn and rotated with the bearing, but a press on it did nothing.

Measured on the UNFIXED build (this device):
    tap on the visible needle at screen (72,391), bearing ~132 deg
    -> logcat: "NTMapTiming {phase: T0-received, token: native:0:4, id: , ...}"
       i.e. the precision layer consumed the press and forwarded it to Dart as a
       blank-map tap; no camera frame followed.
    -> BEARING BEFORE TAP  = non-zero (needle present, 394-402 red px)
       BEARING AFTER  TAP  = UNCHANGED (identical needle pixels and position)
    screenshots 01_*.png / 02_*.png (byte-identical needle geometry)

Ruled out at the same time (each was inspected, not assumed):
  * no Flutter overlay covers the compass — the Stack children above the
    platform view are the bottom-right control column, the bottom disclosure
    card, and boundary/placement chrome; the nearest Listener does not consume;
  * camera/bearing persistence is session-only and only SEEDS
    initialCameraPosition; no code re-issues a stale bearing after a move
    (pinned by tests 3/5 in vs15_m33_auto_face_north_audit_test.dart);
  * compassEnabled: true / rotateGesturesEnabled: true are untouched.

2. FUNCTIONAL FIX (one sentence)
--------------------------------------------------------------------------------
NtPrecisionMapView now resolves, at ACTION_DOWN, whether the press started inside
a visible docked SDK control view (<= 48 logical px, the compass) and, if so,
forwards the whole gesture to the SDK instead of cancelling and consuming it —
so the SDK's own compass click returns the camera to north-up while target and
zoom stay put.
