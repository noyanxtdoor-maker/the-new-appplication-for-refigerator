CLASSIFICATION
================================================================================
FIRST-LAUNCH v47 MIGRATION CONCURRENCY DEFECT CONFIRMED.

Reasoning:
  - The failure reproduces ONLY when `onUpgrade` actually runs (v46 -> v47).
  - With the schema already at 47, no migration runs and startup is clean.
  - The exception site (`app_database.dart:1524`, the `await transaction(...)`
    wrapper inside `onUpgrade`) and `beforeOpen` are UNCHANGED from v46
    (`git diff` confirms the v47 change touched only the five BoolColumns,
    the schemaVersion bump, and the `from < 47` block).
  - Therefore the v47 schema bump is the TRIGGER that first exercised a
    LATENT pre-existing race on the lazy-open path: a main-isolate query
    lazily opened the database in the drift background isolate while another
    connection had already begun the migration's `BEGIN IMMEDIATE`, and the
    resulting unhandled `SqliteException(5)` blocked startup indefinitely.

  This is a genuine owner-blocking defect: a real owner upgrading from v46
  must be able to complete first launch without hanging. The fact that a
  second launch works is NOT a mitigation — the owner never gets past launch
  one.
