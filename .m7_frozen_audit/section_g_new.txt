G5. THE ACTUAL ANSWER, AND WHAT IT MEANS FOR THE OWNER
--------------------------------------------------------------------------------
There was never an app-implemented Auto Face North control, so there is nothing
to restore, and adding one now would be a NEW FEATURE / Maps redesign — which
the handoff explicitly forbids.

The only north-orientation affordance in the accepted build is the SDK-native
Google Maps compass, which:
  * is enabled because the app never sets `compassEnabled`, so the SDK default
    (true) applies — verified in the pinned plugin source
    (`GoogleMapBuilder` creates a bare `GoogleMapOptions()`;
    `Convert.interpretMapConfiguration` applies `setCompassEnabled` only when
    the value is non-null);
  * appears when the map is rotated (rotation gestures remain enabled);
  * returns the camera to north-up when tapped.
That affordance is UNCHANGED: same app source, same plugin version, same
Android configuration as the accepted build.

MOST LIKELY EXPLANATION (for owner confirmation): the owner's "Auto Face North"
is the native Google Maps compass. If so, there is no regression and nothing to
restore. The alternative — that the owner remembers a control this product never
shipped — cannot be resolved without the owner's evidence.
REQUESTED: a screenshot/recording of the accepted build showing the control, so
the exact affordance can be identified rather than guessed.
